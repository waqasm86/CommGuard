# Security

CommGuard is a research prototype and is not a security control. Report code
vulnerabilities through the repository's private
[security advisory form](https://github.com/waqasm86/CommGuard/security/advisories/new).
Do not include model data, credentials, GPU UUIDs from sensitive
infrastructure, or customer artifacts in public reports.

The project does not accept features for monitor tampering, provider evasion,
privilege escalation, covert channels, or attacks against deployed systems.
